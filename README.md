# 気仙沼星空観望会 予約システム 仕様書

## 📖 概要

気仙沼星空観望会のワークショップ予約システムです。参加者が基本情報を入力し、ワークショップの部を選択して予約できるWebアプリケーションです。

### 🎯 主要機能
- マルチステップフォームによる直感的な予約プロセス
- **出席者数選択機能**（1-100名）
- リアルタイムのメールアドレスバリデーション
- **ローディング状態表示**によるUX向上
- ワークショップ参加人数に応じた部の選択
- **アクセシビリティ対応**（WAI-ARIA準拠）
- **iframe埋め込み対応**（Studio環境でのJSONP通信）
- レスポンシブデザイン（モバイル・タブレット・PC対応）
- Google Apps Script APIとの連携
- 当日の交通手段選択＋条件付き「お車台数」（1〜10台）
- **強化されたメール配信システム**（二重配信・iCloud対応）
- **管理者ダッシュボード**（配信状況監視・テスト送信）

### 🌐 デプロイ形式
- **GitHub Pages**: 静的サイトホスティング
- **Google Apps Script**: バックエンドAPI（JSONP対応）
- **Studio埋め込み**: iframe対応

## 📧 メール配信システム（v2.0）

### 配信改善機能
- **二重配信システム**: GmailApp → MailApp自動フォールバック
- **iCloud配信対応**: 簡潔な件名・プレーンテキスト形式
- **配信率向上ヘッダー**: Message-ID・List-Unsubscribe設定
- **詳細ログ機能**: 成功・失敗・エラー詳細記録

### 監視・管理機能
- **リアルタイム配信状況**: 成功率・失敗数・代替送信数

- **テスト送信**: 管理者による配信機能確認
- **設定確認**: Gmailクォータ・送信者情報確認

### 管理者ダッシュボード
- **配信状況監視**: `admin-dashboard.html`

- **エラー分析**: 詳細なエラーログ表示

## 📋 機能仕様

### 1. ユーザーインターフェイス

#### 1.1 ステップインジケーター
- 4段階のプロセス表示
- 現在のステップをビジュアル化
- 完了済みステップの識別

#### 1.2 フォームステップ

**ステップ1: 基本情報**
- **何名でお越しですか？**（必須、1-100名選択）
- 代表者氏名（必須、文字列）
- 来場地域（必須、選択式）
  - 気仙沼市内
  - 宮城県内（気仙沼市以外）
  - 岩手県
  - 福島県
  - その他東北地方
  - 関東地方
  - その他
- メールアドレス（必須、email形式）
- 当日の交通手段（必須、選択式：車／徒歩／自転車／バス／タクシー／その他）
- （車の場合）お車台数（必須、1〜10台の選択式／条件付き表示）
- ワークショップ参加（必須、選択式）
  - 参加する
  - 参加しない（観望会のみ）

**ステップ2: ワークショップ詳細**（ワークショップ参加者のみ）
- ワークショップ参加人数（必須、1-5人）
- 予約する部（必須、動的選択肢）

**ステップ3: 確認・登録**
- 入力内容の表示確認
- 登録ボタン

**ステップ4: 完了**
- 完了メッセージ
- **ホームページへ戻るボタン**（気仙沼星空観望会HP）

### 2. バリデーション機能

#### 2.1 リアルタイムバリデーション
- メールアドレス形式チェック
- 入力中の視覚的フィードバック
- エラー・成功メッセージの表示

#### 2.2 送信前バリデーション
- 必須項目の入力確認
- データ形式の検証
- 部の空席状況確認
- 条件付き必須: 当日の交通手段＝「車」の場合は「お車台数」を1〜10の範囲で必須

### 3. ユーザーエクスペリエンス機能

#### 3.1 ローディング状態管理
- **ボタンローディング表示**:「次へ」ボタンクリック時の処理中表示
- **スピナーアニメーション**: 視覚的なローディングインジケーター
- **非同期処理**: ページ遷移時の適切な待機時間

#### 3.2 アクセシビリティ対応
- **WAI-ARIA準拠**: ページ変更の音声通知
- **キーボードナビゲーション**: タブオーダーの適切な管理
- **スクリーンリーダー対応**: aria-label、aria-hiddenの活用
- **フォーカス管理**: ページ遷移時の適切なフォーカス移動

#### 3.3 iframe埋め込み対応
- **環境検出**: Studio環境での自動JSONP切り替え
- **CORS回避**: iframe内でのAPI通信制限対応
- **レスポンシブ埋め込み**: 外部サイトでの適切な表示

### 4. API連携

#### 4.1 部情報取得
- **エンドポイント**: `${API_URL}?action=getParts`
- **メソッド**: GET（JSONP対応）
- **レスポンス**: 
```json
{
  "success": true,
  "data": [
    {
      "name": "第1部 (19:00-20:00)",
      "capacity": 20,
      "remaining": 15
    }
  ]
}
```

#### 4.2 予約登録
- **エンドポイント**: `${API_URL}`
- **メソッド**: POST（JSONP対応）
- **データ**: FormData形式
- **フィールド**:
  - **来場人数**
  - 代表者氏名
  - 来場地域
  - メールアドレス
  - 当日の交通手段
  - お車台数（条件付き）
  - ワークショップ参加
  - ワークショップ参加人数（条件付き）
  - 予約する部（条件付き）

#### 4.3 JSONP対応
- **iframe環境検出**: `window.parent !== window`
  - 実装では `window.self !== window.top` を使用
- **自動フォールバック**: CORS制限時のJSONP切り替え
- **エラーハンドリング**: 通信失敗時の適切な処理

## 📊 データフロー

```

```

```
入力 → バリデーション → 状態更新 → UI反映
```

```
次へボタン → バリデーション → データ保存 → ステップ更新 → UI更新
```

### 4. 予約送信
```
送信ボタン → 最終バリデーション → API送信 → レスポンス処理 → 完了画面
```
